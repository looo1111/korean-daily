# 韩语日常 · 每天几句

一个给手机用的韩语高频日常用语练习 App：卡片学习 + 发音朗读 + 听音测验 + 间隔复习。

纯静态页面，没有后端、不联网、不需要账号。79 句，分 6 个场景。

## 一、先在电脑上看一眼

双击 `index.html`，浏览器会直接打开（不用起服务器）。

## 二、放到手机上（两种方式）

### 方式 A：托管上去，永久可用（推荐）

GitHub Pages 免费，一次搞定，之后电脑关机也能学：

1. 在 GitHub 新建仓库，比如 `korean-daily`；
2. 把这个文件夹里的 5 个文件传上去（网页上传或 `git push`）；
3. 仓库 → Settings → Pages → Source 选 `main` / `/ (root)` → Save；
4. 等 1 分钟，访问 `https://<你的用户名>.github.io/korean-daily/`；
5. 手机 Safari 打开这个网址 → 分享 → **添加到主屏幕**。

之后从桌面图标点开就是全屏 App，断网也能用。

> 也可以用 Vercel / Netlify：把文件夹拖进去即可，同样免费。

### 方式 B：只在同一个 WiFi 下临时用

```bash
cd "/Users/lxx/Documents/dsh/韩语学习"
python3 -m http.server 8080
```

手机浏览器打开 `http://<这台 Mac 的局域网 IP>:8080`。

缺点：关掉终端或电脑休眠就打不开了；而且 `http://` 局域网地址在 iPhone 上加到主屏幕后没有离线缓存。

## 三、怎么用

- **学习**：先自己读一遍 → 点卡片看意思和罗马音（会自动朗读）→ 选「不熟 / 还行 / 很熟」。
  选「不熟」的句子 10 分钟后会再出现；「很熟」的隔几天再见。就这样自动排复习。
- **测验**：中文→韩语、韩语→中文、听音选句三种。答错的句子自动回到复习队列。
- **手册**：按分类看全部句子，支持搜韩语 / 中文 / 罗马音，点一下就能听。
- **我的**：学了几个、连续几天、各分类掌握度；主题、罗马音开关、朗读速度、清空记录。

## 四、语法功能

每句都带三层讲解，从浅到深：

1. **卡片背面**：翻面后有一行小字，比如 `해요体 · -아요/어요/해요 日常敬语`，一眼看出这句的礼貌等级和核心句型。
2. **逐词拆解弹层**：点卡片背面的「逐词拆解 · 语法 ›」，或手册里点任意一行，会从底部弹出：
   - 逐词切分（哪部分是「安宁」、哪部分是敬语词尾）
   - 语法点说明（为什么这样说、容易错在哪）
   - 相关句型（点一下直接跳到语法页对应条目）
3. **句型页**（底部「讲解」→ 第一个分段）：31 个句型，每个都有一句解释和使用它的全部例句。
   比如点开「-아/어 주세요 请为我做…」，能看到 11 句用到这个句型的例句。

这样是「先记住句子，再反推规律」，比先背语法表更容易开口。

## 五、变音规则

韩语的写法和读法差得很远：`감사합니다` 读作 [감사함니다]，`맵게` 读作 [맵께]，`어떻게` 读作 [어떠케]。
App 里在三个地方体现：

1. **卡片背面**：罗马音下面多一行 `[감사함니다]`，这句的标准发音。44 / 79 句有变化，其余按字面读。
2. **逐词拆解弹层**：多一栏「怎么读」，给出方括号发音 + 触发了哪几条规则（点规则标签直接跳到规则页）。
3. **讲解页 · 变音规则**（底部「讲解」→ 第二个分段）：8 条核心规则，每条都有一句话说明、
   4 组词对照（如 `한국어 → [한구거]`），以及本站用到这条规则的全部句子。

8 条规则：连音、鼻音化、紧音化、送气化、ㅎ 脱落、流音化、口盖音化、ㄴ 添加。
其中流音化（신라 [실라]）、口盖音化（같이 [가치]）、ㄴ 添加（꽃잎 [꼰닙]）在现有 79 句里没触发，
仍然保留说明和例子——它们在日常对话里出现频率很高。

朗读用的是系统 TTS，它会自己按变音读出来，不用手动改文本。

## 六、发音

用的是手机自带的语音合成（Web Speech API，`ko-KR`），不联网、不花钱。

iPhone 想更自然：设置 → 无障碍 → 朗读内容 → 声音 → 韩语 → 下载（Yuna 音色）。
安卓：设置 → 系统 → 语言和输入法 → 文字转语音 → 安装韩语语音数据。

## 七、改内容

所有句子都在 `index.html` 里的 `var ITEMS = [...]`，一条长这样：

```js
{id:"g3", cat:"greet", ko:"감사합니다", ro:"gamsahamnida", zh:"谢谢", lv:"합니다体",
 pat:["bnida","hanja"],
 parts:[["감사","感谢（汉字词）"],["합니다","하다 的正式体"]],
 note:"합니다 是 하다 的正式体（-ㅂ니다）。"},
```

- `id` 唯一即可；
- `cat` 取值：`greet` 问候 / `order` 点餐 / `shop` 购物 / `way` 问路 / `help` 求助 / `polite` 客套；
- `lv` 礼貌等级，`pat` 关联句型（讲解页自动归类），`parts` 逐词拆解，`note` 语法点；
- 想加分类：改 `CATS` 数组，加一行 `["新key","显示名"]`；
- 发音有变化时，在文件里的 `SOUND` 表加一行（句子本身不用改）：

```js
g3:["감사함니다",["nas"]]
// 第一个是标准发音，第二个是触发的规则 key：
// yeon 连音 / nas 鼻音化 / tense 紧音化 / asp 送气化 / hdrop ㅎ脱落 / liq 流音化 / pal 口盖音化 / addn ㄴ添加
```

改完保存，手机上刷新一次即可（已装到桌面的话，重新打开会自动用新版本）。

## 九、数据

学习记录存在浏览器的 `localStorage`（键名 `kr-daily-v1`），**只在这台设备的这个浏览器里**。

换浏览器、换手机、清除网站数据都会丢；想长期不丢，用同一个浏览器一直用即可。
